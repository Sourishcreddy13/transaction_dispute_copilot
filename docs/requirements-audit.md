## Scope notes

The original assessment file marks frontend visual polish as out of scope. The frontend here is intentionally functional rather than a scoring dependency: it presents synthetic customer/account/card/statement/transaction/case information and drives the dispute and review APIs.

The fallback provider is part of the current execution policy because the project owner changed the assessment requirement after the original Gemini-only brief. This must be recorded in `docs/deviations.md` for submission.
