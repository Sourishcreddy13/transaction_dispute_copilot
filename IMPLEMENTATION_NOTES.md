# Implementation Notes

This repository implements the finalized Transaction Dispute & Fraud-Triage Copilot architecture.

## Runtime

- Python 3.12 pinned through `.python-version`
- uv-managed dependencies in `pyproject.toml` and `uv.lock` generated by the repository owner after dependency resolution
- Gemini primary -> Groq fallback
- Chroma + SentenceTransformers RAG
- Presidio PII analysis
- LangGraph AsyncSqliteSaver checkpointing
- MCP stdio server consumed through `langchain-mcp-adapters`
- OpenTelemetry + Phoenix
- DeepEval qualitative evaluation

## Architectural implementation

- `src/graph.py`: authoritative LangGraph orchestration
- `src/agents/`: three specialized workers
- `src/context/`: write/select/compress/isolate context engineering
- `src/memory/`: trust-filtered durable memory + LangMem integration boundary
- `src/tools/rag_tool.py`: bounded agentic policy retrieval
- `src/guardrails/`: output/release invariants
- `src/observability/`: Phoenix/OTel instrumentation
- `mcp_server/server.py`: actual banking MCP data plane
- `app/core/`: domain models, deterministic engines, persistence, security and provider gateway
- `frontend/index.html`: functional analyst banking workspace

## Evidence generation

Run:

```bash
uv run python scripts/generate_evidence.py
```

with local Phoenix running. The script executes the synthetic seed, memory persistence proof, MCP smoke test, deterministic public/hidden/mutation evaluation, DeepEval qualitative suite, failure matrix, Phoenix trace export, golden signals, dashboard and strict evidence validation.

## Verification note

The application code is designed for the pinned dependency set. Library behavior marked for verification in the architecture remains a runtime compatibility concern. The repository owner's `uv.lock` should be regenerated and committed after the final dependency set is installed locally.
